# Repository guidance for future sessions

This repository contains portable coding-agent skills, not an application to reorganize. Each skill lives at `skills/<name>/SKILL.md`; put focused, task-specific guidance in `skills/<name>/rules/` and link to it from the skill's rule index. Keep descriptions discoverable, advice actionable, and examples consistent with current framework conventions. Update the skills table in `README.md` when adding a skill.

Run `pnpm format:check` after editing Markdown (and `pnpm format` if formatting needs correction). Review the diff and run any relevant checks before finishing.
